# ML beyond the PES: Hands-on session

**Tutors**: Joseph W. Abbott, Matthias Kellner, Paolo Pegolo, Filippo Bigi

---

This folder contains three exercises on machine learning for targets beyond the
potential energy surface.

## Setup

Each exercis requires its own environment to avoid any versioning conflict. At the top of each exercise markdown file there will be an indication about which environment to use, e.g.

```bash
workon metatomic
```

If necessary, JupyterLab can then be run from the terminal as:

```bash
jupyter lab
```

---

## Exercises

Access each exercise folder as instructed by the presenting tutor. Then, follow the instructions in `.md` file contained in that folder.
